# Validation

The entire bundle was copied to a fresh temporary directory outside the checkout. `python3 -I algorithm.py`, `python3 -I replay.py` and `python3 -I verify.py` passed with a minimal environment and no credentials/network requests.

The selected algorithm command executes the original Python signature/match definitions against the exact provider-dispatch source, resolved links and model declaration. It reproduces all 15 operation-context hashes, 13 fields and original source-line bindings. This is a real source-based algorithm computation; it does not reconstruct the earlier ownership links or full corpus. Archived module top levels are never executed.

The recorded-result replay covers 115 public/held cases, 166 fresh paid questions and both round costs. It reparses original public Claude answer text, checks frozen identity and verdict hashes, recomputes report outcomes from original admissions, preserves all 32 missing first-round novel answers, and confirms zero incremental supplemental reports across 18 treatment-only pairs. Source-D categories remain separate from pre-update metrics and provider labels.

Checks cover selected full-source hashes, held-source exclusion, local Markdown links and manifest hashes. Sensitive-pattern scanning traverses every file and decompresses gzip archives, checking private repository/incident identifiers, common credential formats and private-key markers. This is not proof that arbitrary unknown secret formats are impossible. The 28 held records contain no source bodies, excerpts, rendered prompts, raw answers or answer prose.

The exact local-ledger hydration path verifies the original ledger SHA256 and rendered prompt hashes before restoring one held case. Public source hydration reads already available pinned Git objects only. Four study background hashes match hash-verified manifests in the separately pinned goldens catalog; the held fifth does not. No corpus refit or new experiment was run.

Proposed branch links become live after root publishes. Full product tests and self-lint were not run because this is an isolated research handoff with no production/CI edits or push. The [data contract](DATA-CONTRACT.json) lists external inputs needed for a full reconstruction and excludes private histories from public reproduction claims.
