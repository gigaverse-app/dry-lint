## TLDR

Adding retrieval signals can improve candidate funding while producing no new useful reports. This PR preserves the signal-ensemble study with original code, exact public questions and answers, and a runnable operational gate example, so future work can reproduce that distinction. Do not promote the learned replacement, universal two-slot blend or stricter gate. Retain the smaller one-block add-on after TF-IDF20 as a scoped funding result, without claiming new paid-report recall.

[Canonical study](https://github.com/gigaverse-app/dry-lint/blob/research/study-signal-ensemble/docs/research/signal-ensemble/README.md) explains the hypothesis, recipes, matched denominators, source reviews, costs and limits.

```text
BEFORE: full sparse baseline -> original budget -> unchanged judge
TESTED: protected baseline -> bounded block/dense extras -> remaining budget -> same judge
PUBLICATION: original gate + frozen full-background state -> public answer replay -> scoped decisions
```

The writeback case was recognized as duplicate at 0.62 but failed the 0.80 report rule; source review accepted only seven-field state copying. The original gate also admits shared SDK vocabulary that the model and source review reject as a new operation. Useful emitted controls were already baseline-funded.
