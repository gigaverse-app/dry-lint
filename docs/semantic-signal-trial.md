# Semantic signal trial

Try three static signals without changing the shipped detector: imported API identity, arguments bound to known
undecorated Python functions, and direct field dependencies of returns/assignments. Evaluate each separately and
combined, at the existing thresholds and three-candidate budget. Use the old backend judgments only as a
regression set. Judge fresh baseline and newly proposed pairs from backend and gigaverse-ai before inspecting
per-variant retention. Do not promote a variant based only on synthetic examples or repeatedly consulted labels.

Implementation, sampling and results are in progress. No runtime defaults or deployment behavior change.
